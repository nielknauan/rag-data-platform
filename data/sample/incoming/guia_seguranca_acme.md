# Guia de Segurança da Informação — ACME Dados Ltda. (empresa fictícia)

> Documento fictício usado para demonstrar a ingestão incremental: ele "chega" depois da primeira carga.

## Controle de acesso

O acesso a bases com dados pessoais segue o princípio do menor privilégio. Permissões são revisadas a cada trimestre pelo gestor da área e todo acesso a dados sensíveis exige autenticação multifator.

## Criptografia

Dados pessoais devem ser criptografados em repouso e em trânsito. Chaves de criptografia ficam em cofre gerenciado e são rotacionadas anualmente.

## Ambientes de desenvolvimento

É proibido copiar dados pessoais reais de produção para ambientes de desenvolvimento ou teste. Use dados sintéticos ou bases anonimizadas.
